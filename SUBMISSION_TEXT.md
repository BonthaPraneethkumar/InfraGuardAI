# Hackathon Submission Text

## Project Name
InfraGuard AI — Intelligent Urban Infrastructure Monitoring & Response

## One-line description
An AI-assisted smart-city platform that transforms citizen-reported infrastructure problems into privacy-aware, prioritized, location-linked cases and routes them to the correct department.

## Core flow
Citizen → Photo + Voice + Location → Privacy Gate → Voice-to-Text → AI Triage → Department Routing → Officer Dashboard → Resolution → Citizen Tracking → Analytics

## Technology
- Frontend: HTML, CSS, JavaScript
- Backend: Python, FastAPI, Uvicorn
- Privacy screening: OpenCV
- Speech AI: Sarvam Saaras
- Reasoning AI: Sarvam-105B
- MVP database: SQLite
- Production direction: Azure

## Responsible AI
AI provides recommendations. A human officer remains responsible for case review, action and closure.
